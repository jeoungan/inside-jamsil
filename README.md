# inside · 잠실야구장 3D

[공개 사이트 열기](https://jeoungan.github.io/inside-jamsil/)

잠실야구장 내부 공간을 둘러보고 좌석·편의시설까지 모델 안에서 길을 찾는 Three.js 앱입니다. 로그인 없이 휴대폰과 PC에서 열 수 있습니다.

- 휴대폰을 세로로 들면 앱 전체를 시계 방향으로 90도 돌려 가로 화면으로 표시
- 회전된 화면에 맞춘 시설 터치 선택, 3D 회전·핀치 확대, 왼쪽 이동·오른쪽 시점 조작
- 계단과 얇은 연결 통로의 실제 바닥을 따라 이어지는 밝은 유도선
- 기둥 사이의 좁은 틈보다 여유 있는 통로를 우선하는 길찾기
- 화면 옆에 붙는 작은 길찾기 탭, 같은 높이의 왼쪽 이동·오른쪽 시점 안내
- 3D에 표시된 게이트·출입구13곳에서 시작 위치 선택
- 좌석 구역 입력과 길찾기 중심의 간단한 화면, 열·번호는 선택 입력
- 휴대폰에서는 앱 화면과 함께 회전하는 가로 숫자 키패드로 구역·열·번호 입력
- 티켓 사진 촬영 또는 사진 선택 → 구역·열·번호 확인 → 입력란에 적용
- 화면 방향을 바꿀 때 진행 중인 손동작을 정리하고 현재 몸 위치 보존
- 1층 · 2층 · 2.5층 · 3층 · 4층 탐색
- 현재 모델상의 위치에서 좌석·편의시설 길찾기
- 스와이프 이동과 PC 키보드·마우스 조작
- 한국어 시설명과 아이콘

휴대폰을 세로로 든 채 열어도 회전 안내 없이 가로 화면을 바로 사용할 수 있습니다. 기기를 가로로 들면 화면도 정상 가로 배치로 전환합니다. 조작 방향은 표시된 앱 화면을 기준으로 합니다. 걷는 화면의 왼쪽 절반에서 손가락을 움직이면 전후·좌우로 이동하고, 오른쪽 절반에서는 시점을 조절합니다. 두 손가락을 동시에 사용할 수 있으며 이동용 손가락을 떼면 정지합니다. 목적지 선택창은 필요할 때 펼치고 걷기를 시작하면 접힙니다. 검색 키보드가 나타나면 입력 패널이 남은 화면을 채웁니다. 전체 화면 기능은 지원 브라우저에서 선택할 수 있습니다. PC와 태블릿의 화면 방향은 제한하지 않습니다.

## 로컬 실행

좌석은 직접 입력이 기본입니다. 같은 열·번호가 여러 구역에 반복되므로 구역까지 입력해야 합니다. 사진 스캔은 한국어 표기를 먼저 읽고 필요할 때 영어 표기도 읽습니다. 결과를 확인한 뒤 적용하며, 적용 후 숫자를 수정할 수 있습니다. 일부만 읽힌 티켓은 이전 좌석값을 섞지 않고 빈 칸으로 남깁니다. 여러 좌석이 함께 보이면 티켓 한 장만 다시 촬영하도록 안내합니다.

사진과 인식 문자열은 서버에 보내거나 저장하지 않습니다. OCR 엔진·한국어/영어 인식 데이터는 이 앱과 같은 주소에서 필요할 때만 내려받습니다. 첫 스캔은 네트워크와 기기 성능에 따라 잠시 걸릴 수 있습니다. 흐리거나 비스듬한 사진, 특수 좌석 표기 등은 직접 수정이 필요할 수 있습니다. 스캔은 기존 좌석 안내 지원 범위를 확대하지 않습니다.

Node.js 22 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

## 배포

`main`에 push하면 `.github/workflows/deploy.yml`이 의존성을 설치하고 GitHub Pages에 자동 배포합니다.

```sh
npm run build:github
```

GitHub Pages 빌드는 `/inside-jamsil/` 경로를 사용합니다. 일반 루트 경로 배포에는 `npm run build`를 사용합니다. 원본 참고 사진·PDF, 모델 내보내기, 계정별 호스팅 정보와 로컬 로그는 공개 저장소에 포함하지 않습니다.

실행·빌드 명령은 `scripts/prepare-ocr.mjs`로 잠금파일에 고정된 Tesseract.js 7.0.0과 언어 자료를 `public/ocr/`에 준비합니다. 생성 파일은 Git에 넣지 않고 빌드에 포함합니다. 스캔에는 브라우저 Web Worker와 WebAssembly가 필요합니다. 카메라 버튼은 지원 모바일 브라우저의 촬영 UI를 요청하며, 지원하지 않으면 사진 선택을 이용할 수 있습니다.

## 모델의 범위

공개 도면·구단 안내도·사진을 대조한 연구 모델입니다. 층고, 좌석 좌표와 일부 연결 단면은 추정이며 실제 현장 동선·출입 가능 여부는 검증하지 않았습니다. 구역만 입력하면 구역 입구까지 안내하고, 열·번호를 입력하면 지원하는 좌석 앞까지 안내합니다. 지원하지 않는 정확한 좌석은 업데이트 예정과 사과 문구를 표시하며 다른 목적지로 바꾸지 않습니다. 시설별 근거는 앱의 '모델 근거'와 소스 데이터에 있습니다.

검증된 번호는 11개 구역 203개 주소이며, 위치가 등록된 편의시설 80곳과 위치 미확인 정보 2곳을 구분합니다. 시설의 실제 당일 영업 여부는 보증하지 않습니다.
