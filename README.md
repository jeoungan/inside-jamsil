# inside · 잠실야구장 3D

[공개 사이트 열기](https://jeoungan.github.io/inside-jamsil/)

잠실야구장 내부 공간을 둘러보고 좌석·편의시설까지 모델 안에서 길을 찾는 Three.js 앱입니다. 로그인 없이 휴대폰과 PC에서 열 수 있습니다.

- 세로 화면의 접이식 목적지 패널, 가로 화면의 오른쪽 패널
- 1층 · 2층 · 2.5층 · 3층 · 4층 탐색
- 현재 모델상의 위치에서 좌석·편의시설 길찾기
- 스와이프 이동과 PC 키보드·마우스 조작
- 한국어 시설명과 아이콘

## 로컬 실행

Node.js 22 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

## 배포

`main`에 push하면 `.github/workflows/deploy.yml`이 의존성을 설치하고 GitHub Pages에 자동 배포합니다.

```sh
npm run build:github
```

GitHub Pages 빌드는 `/inside-jamsil/` 경로를 사용합니다. 일반 루트 경로 배포에는 `npm run build`를 사용합니다. 원본 참고 사진·PDF, 모델 내보내기, 계정별 호스팅 정보와 로컬 로그는 공개 저장소에 포함하지 않습니다.

## 모델의 범위

공개 도면·구단 안내도·사진을 대조한 연구 모델입니다. 층고, 좌석 좌표와 일부 연결 단면은 추정이며 실제 현장 동선·출입 가능 여부는 검증하지 않았습니다. 확인된 좌석 번호만 좌석 앞까지 안내하고, 미확인 번호는 해당 구역 입구까지 안내합니다. 시설별 근거는 앱의 '모델 근거'와 소스 데이터에 있습니다.

검증된 번호는 11개 구역 203개 주소이며, 위치가 등록된 편의시설 80곳과 위치 미확인 정보 2곳을 구분합니다. 시설의 실제 당일 영업 여부는 보증하지 않습니다.
